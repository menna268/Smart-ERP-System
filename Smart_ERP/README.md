# Smart ERP System

A professional ERP (Enterprise Resource Planning) web application built using Flask.

## Features

- User Authentication
- Dashboard
- Inventory Management
- Sales Management
- Invoice Generation
- Reports
- Role-Based Access Control

## User Roles

### Admin

- Manage Products
- View Dashboard
- View Reports

### Manager

- Everything in Admin
- Add Users
- Manage Employees

### Employee

- Search Products
- Create Sales

## Technologies

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- JSON
